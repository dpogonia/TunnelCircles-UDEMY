# Tunnel Circles

Четыре круга в глубину для visionOS.

## Что умеет приложение

На сцене четыре контура. Ползунок Depth отодвигает их назад. Два выбора цвета красят чётные и нечётные круги.

## Стек

SwiftUI.

## Запуск

```bash
git clone https://github.com/dpogonia/TunnelCircles-UDEMY.git
cd TunnelCircles-UDEMY
open VisionApp.xcodeproj
```

Запустите схему **VisionApp** в симуляторе visionOS. Цель сборки — visionOS 1.2.
