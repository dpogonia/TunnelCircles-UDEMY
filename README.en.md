# Tunnel Circles

Four circles set back in depth for visionOS.

## What it does

The scene shows four outlines. The Depth slider pushes them backward. Two color pickers paint the even and odd circles.

## Stack

SwiftUI.

## Run

```bash
git clone https://github.com/dpogonia/TunnelCircles-UDEMY.git
cd TunnelCircles-UDEMY
open VisionApp.xcodeproj
```

Run the **VisionApp** scheme in the visionOS simulator. The deployment target is visionOS 1.2.
